# Customer Shopping Behavior Analysis

## Overview

This project is an end-to-end data analytics project focused on analyzing customer shopping behavior and identifying meaningful patterns and business insights.

The project covers data loading, exploratory data analysis, data cleaning, SQL analysis, Power BI visualization, project reporting, and presentation.

## Dataset

The dataset contains customer shopping behavior information, including:

- Customer demographics
- Age and gender
- Product categories
- Purchase amount
- Discounts
- Payment methods
- Shopping frequency
- Customer ratings

## Tools

- Python
- Pandas
- Jupyter Notebook
- SQL
- MySQL / PostgreSQL / SQL Server
- Power BI
- Microsoft Word
- Gamma

## Project Steps

### 1. Data Loading

The dataset was loaded into Python using Pandas and inspected to understand its structure, columns, and data types.

### 2. Exploratory Data Analysis

EDA was performed to understand customer demographics, purchasing patterns, product categories, missing values, duplicates, and data distributions.

### 3. Data Cleaning

The data was cleaned by handling missing values, duplicates, inconsistent values, data types, and column names.

### 4. SQL Analysis

SQL queries were used to analyze customer purchasing behavior and answer business-related questions related to spending, products, discounts, payment methods, and customer behavior.

### 5. Power BI Dashboard

An interactive Power BI dashboard was created to visualize key metrics and customer shopping patterns.

### 6. Project Report

A detailed project report was created documenting the project objective, methodology, analysis, findings, and insights.

### 7. Presentation

A presentation was created using Gamma to summarize the project, analysis, dashboard, and key findings.

## Dashboard

The Power BI dashboard provides an interactive overview of customer shopping behavior.

Key areas include:

- Customer demographics
- Purchase behavior
- Product categories
- Purchase amount
- Discounts
- Payment methods
- Customer ratings
- Shopping frequency

## Results

The analysis helped identify patterns in customer purchasing behavior, spending, product preferences, discount usage, payment methods, and shopping frequency.

These insights can support better understanding of customer behavior and data-driven decision-making.
